# 首版实现与验证记录

开发日期：2026-10-30（Asia/Shanghai）。

## 对初始计划的落实

根据提供的 XMAX 临时密钥配置、官方素材和已验证 SDK 接口，采用 Vite + TypeScript + 单个 Node 服务。照片模式将本地选帧作为静态视频流输入；动态模式输入本地短视频。实际生成经过 XMAX X2.1，不使用图片叠加冒充试穿。

视频输入限制为 10 秒和 30 MB。照片模式收到画面后最多再生成 3 秒，动态模式最多 8 秒。含签发和 RTC 初始化的总等待上限为 60 秒；超时若已收到画面则保留结果，没有收到则明确提示失败。

应用不在后端存储原视频、人物图片和结果图片，因此无需原计划中的图片文件保留与清理任务。XMAX 存储服务会接收服饰参考图，其保留时间未由本应用确认，界面和 README 均明确区分第三方处理规则。

连续短片的录制由浏览器完成；没有实现实时摄像头直接推流，而是先录制有限时长素材再生成。没有账户、支付、订单、3D 建模或尺码判断。

## 真实 API 验证

已使用提供的 API Key 成功签发临时密钥、上传服饰参考图、建立 X2.1 实时连接并取得真实全身换装照片，试穿结束后确认临时密钥撤销。

初次签发遇到 12 秒网络超时；第二次签发成功但 45 秒初始化窗口未收到画面。增加明确的 60 秒总等待预算，并绑定 SDK 本地预览轨道后，已取得真实换装结果。照片模式随后缩短为收到画面后最多再生成 3 秒。

上衣参考含有整套造型信息时，模型也改变了下装和鞋履，说明只靠提示词不能保证未选择的服饰完全不变。已收窄上衣参考图裁剪，并在 README 中记录效果限制；多件组合和配饰在产品中标为实验功能。

后续验证已成功完成：

- 下装：全身模特的白裙替换为参考牛仔裤，原有黑色上衣保留。
- 帽子：半身视频选帧中的人物戴上参考白色棒球帽，背景和面容保留。
- 动态短片：半身人物视频换上米白外套，保留挥手动作，实际下载到 VP8 WebM 视频（832×468，133 个可解码画面）。

以上三次均正常保存完成，未出现浏览器运行时错误，后端记录的临时密钥撤销均成功。

随后三件组合也已跑通：一张拼接参考图、一次 API 会话，同时生成米白外套、牛仔裤和白色帽子。但模型带入了上衣参考中的黑色裙摆细节，所以多件搭配仍保留实验标记。尚未实测眼镜，不把它或所有平台链接适配宣称为已验证。五类真实结果位于 `.local/verification/live`。
