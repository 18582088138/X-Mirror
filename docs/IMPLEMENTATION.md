## 对初始计划的落实

根据提供的 XMAX 临时密钥配置、官方素材和已验证 SDK 接口，采用 Vite + TypeScript + 单个 Node 服务。照片模式将本地选帧作为静态视频流输入；动态模式输入本地短视频。实际生成经过 XMAX X2.1，不使用图片叠加冒充试穿。

视频输入限制为 10 秒和 30 MB。照片模式收到画面后最多再生成 3 秒，动态模式最多 8 秒。含签发和 RTC 初始化的总等待上限为 60 秒；超时若已收到画面则保留结果，没有收到则明确提示失败。

应用不在后端存储原视频、人物图片和结果图片，因此无需原计划中的图片文件保留与清理任务。XMAX 存储服务会接收服饰参考图，其保留时间未由本应用确认，界面和 README 均明确区分第三方处理规则。

连续短片的录制由浏览器完成；没有实现实时摄像头直接推流，而是先录制有限时长素材再生成。没有账户、支付、订单、3D 建模或尺码判断。
